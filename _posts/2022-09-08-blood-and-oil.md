The third project is a type of sidescroller game, with the option of choosing between 3D or 2D. We chose 3D and used the game [Guns, Gore and Cannoli 2](https://store.steampowered.com/app/525510/Guns_Gore_and_Cannoli_2/) as a reference game.

This is our first project outside Unity using the school's engine TGE. TGE has no editor and the usual pipeline uses Unity as editor and exports its scene as JSON.

- Project name: Platformer
- Period: 25 Jan - 8 Mar
- Speed: 50%
- Group name: P1G5
- Engine: Unity (editor) / TGE
- Language: C#

## My area

My work on this project was primarily concerned with the pipeline between TGE and Unity, dealing with rotational issues and supporting other disciplines.
