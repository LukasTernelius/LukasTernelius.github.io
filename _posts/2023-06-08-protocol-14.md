This is the fifth game we make here at TGA and it's now made completely in our own engine. This project was rather short and is aimed to bring everyone up to speed on using this engine and Unreal as an editor. A learning process to be sure!

- Project name: Narrative game
- Period: 25 Jan - 8 Mar
- Speed: 50%
- Group name: Smoggers
- Engine: Ghastlight
- Language: C++

## My area

On this project I did a lot of work on the pipeline, but started learning a lot of the core engine stuff in my free time and started taking over that work as well. My work here ranged from setting up the "level loader" and asset/material handling for models/textures, to setting up shaders and fixing lighting in the scene. I also started optimizing mine and other people's code so that we could clear the performance requirements for the games, and was responsible for turn-ins of projects.
