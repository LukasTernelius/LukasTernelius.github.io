The sixth project is a Diablo clone where we are given a certain art style to follow, to mimic making a game on demand.

- Project name: Spite
- Period: 25 Jan - 8 Mar
- Speed: 50%
- Group name: Smoggers
- Engine: Ghastlight
- Language: C++

## My area

In this project I really started to take a broader interest in deeper engine/core functionality. As I had finished the engine course and had spent a lot of time developing my own engine, I was a lot more comfortable with that kind of code as well.

Systems I worked on during this project:

- Frustum culling
- Debug drawer and frame statistics
- Collision trigger system
- New and improved material loading system
- Instancing system for meshes
- Optick & crashlog reporting to our Discord server

I also spent a lot of time debugging problems and honing my debugging skills by helping my group mates with the problems that they got stuck on, earning me a bit of a reputation for excelling at this.
